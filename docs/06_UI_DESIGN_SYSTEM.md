# Ishara Interface & Design System

- **Official identity:** supplied Ishara hand/speech logo. Do not recolor the uploaded artwork. A symbol-only crop is generated for launcher use without changing the hand shape.
- **Visible attribution:** Developed by **Md. Atif Absar** on Welcome / About / Home footer.
- **Public app language:** “Ishara”, “Communication beyond words”. No visible CSE 2200 / academic task name.
- **Colors:** primary `#087B74`, deep `#003E46`, mint `#DDF4EE`, white `#FFFFFF`, near-white `#F7FAF9`, body `#143D3A`, muted `#66817E`, lime accent `#D6F46B`.
- **Typography:** Android native sans-serif; 26–30sp page titles, 16–17sp item titles, 14–16sp body. When captions are active, 23sp live text.
- **Radii and spacing:** 16dp primary buttons, 20–23dp cards, 22dp side margin, 12–20dp component spacing.
- **Accessibility rules:** visible button labels, 48dp minimum touch targets, no information conveyed only by color, permission reasons, clear empty/error states, truthful description of AI confidence. Screen-reader audit required before production.
- **UI sequence:** Welcome first run -> Home -> function; consistent Back and Android system navigation.
- **Photo privacy:** user's real camera feed stays in preview; the UI should not claim a virtual emulator scene is an actual hand.
- **Future polish:** bottom navigation, dark theme, dynamic text scaling, high contrast toggle, RTL/Bangla localization, lecture segment highlights, home tiles with icon assets and state persistence.
