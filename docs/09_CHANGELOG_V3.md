# Ishara 3.0 Changelog

**Preserved:** camera / gesture MediaPipe pipeline, model auto-install, Bangla speech bound service, SQLite saved phrases/history, internal ContentProvider, RecyclerView, JSON/HTTP demo, optional Firebase and battery broadcast.

**Added:** official uploaded logo and cropped launcher icon; first-run Welcome and About screens with developer credit; redesigned Home; Java `CaptionController`, LiveCaption Activity, Two-way Conversation chat; Gesture Learning list; Progress Dashboard; SQL store for captions/trials/usage; context expansion from 3 to 5; Sentence Builder word tiles; Picture Board; manual test plan and detailed syllabus blueprint.

**Removed from consumer UI:** CSE 2200 text / lab badge. Academic information remains in project documentation as context.

**Deferred:** 15+ physically distinct recognized gestures, genuine Bangla Sign Language translation, always-on background caption service, validated WER or model precision statistics, full accessibility certification and Play Store production configuration.
