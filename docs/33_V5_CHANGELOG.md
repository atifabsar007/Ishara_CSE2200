# Ishara 5.0 Changes

- Added session-scoped Wi-Fi Peer Link with JSON message exchange, six-digit session code and private IPv4 validation; clear unencrypted transport warning.
- Added gesture and sentence builder -> Peer Link compose-first navigation.
- Added four branching everyday roleplay scenarios, SQLite saved paths and practice scores.
- Added optional Inside Ishara developer demonstration panel with lifecycle, isolated SQLite CRUD, JSON parsing, battery broadcast, speech, Intents and real socket navigation.
- Reordered Home to Gesture Studio first, Live Captions second, Ishara Quest third, then all other communication tools.
- Preserved app logo and attribution to Md. Atif Absar; did not add academic course text to normal UI.
- Added Java-only checks for scenario graph reachability and private IPv4/code/message validation.
- Preserved all Ishara 4.0.1 classes and modules. External MediaPipe model and official Gradle wrapper assets remain separate.
- Status: Source validation completed; full Android build and physical-device acceptance remain required.
