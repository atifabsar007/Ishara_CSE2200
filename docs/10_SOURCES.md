# Technical References and Licensing Review Checklist

The following vendor docs are useful for implementation and should be checked during future upgrades:

- https://developer.android.com/reference/android/speech/RecognitionListener — partial/final/segment callbacks
- https://developer.android.com/reference/android/speech/RecognizerIntent — recognition configuration
- https://developer.android.com/guide/topics/media/speech-recognition — speech feature fundamentals
- https://developer.android.com/training/camerax — CameraX and lifecycle
- https://developers.google.com/edge/mediapipe/solutions/vision/gesture_recognizer — supported built-in classes
- https://developers.google.com/edge/mediapipe/solutions/vision/gesture_recognizer/android — Java/Kotlin Android recognition task
- https://developer.android.com/guide/components/activities/activity-lifecycle — Activity callbacks
- https://developer.android.com/develop/ui/views/layout/recyclerview — adapters/ViewHolders
- https://developer.android.com/guide/topics/providers/content-providers — ContentProviders
- https://developer.android.com/develop/background-work/services/fgs/restrictions-bg-start — microphone foreground restrictions
- https://docs.gradle.org/current/userguide/gradle_wrapper.html — official wrapper setup/security

All third-party libraries and model files have their own licenses. Review them before distribution. Uploaded Ishara logo remains user-provided artwork; do not assume that the source ZIP redistributes the MediaPipe model binary.
