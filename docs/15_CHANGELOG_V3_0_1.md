# Ishara 3.0.1 changes

- Added explicit speech errors and bounded segment restarting.
- Added experimental auto Bengali/English switching (API 34+ supporting speech service required).
- Enhanced live transcription display and microphone status.
- Added in-app microphone diagnostic and permission shortcut.
- Added language choices to Two-way Conversation.
- Changed Smart Shortcuts labels to clarify that they are phrase usage frequency, not AI predictions.
- Preserved gesture recognition, model retrieval, UI branding, existing local databases, and other Java syllabus features.
- Updated versionName from 3.0.0 to 3.0.1.

## Known limitations

No guarantee of continuous transcription or interim streaming on every Android emulator/device. Google speech service and model support are hardware/device/provider-dependent. Full Gradle build and physical device test pending.
